# PCSO Lotto Draw Machine (auto-updating)
Files: `index.html` (the app), `results.json` (latest draws), `scripts/update_results.py` + `.github/workflows/update-results.yml` (daily updater).
See SETUP steps in the chat. After upload: Settings > Pages > Deploy from branch `main` / root. Then Actions > "Update lotto results" > Run workflow to test.
